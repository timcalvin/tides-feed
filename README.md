# Tides puzzle feed

Public daily puzzle feed for the Tides iOS app, served by GitHub Pages at
<https://timcalvin.github.io/tides-feed/puzzles.json>.

This repo only ever holds puzzles dated up to a week ahead: `puzzles.json` through tomorrow, and `upcoming.json` with the rest scrambled until their day. It is written automatically by a daily
GitHub Action in the private puzzle bank; don't edit `puzzles.json` by hand.
